# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/otterfamily/ottersql/security/advisories/new). Do not open a public issue.

Include what you found, how to reproduce it, and the impact you expect. You will get a reply as soon as the maintainer can look at it.

## Supported versions

ottersql has not been released yet, so no version is supported. This section will list supported versions once releases begin.
